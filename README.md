## Quick start

Clone this repository, then follow each project README. Most scripts are read-only. Run them on **your own test systems** with appropriate permissions. AWS Terraform creates resources and may incur costs; destroy them after testing.

```bash
git clone https://github.com/YOUR_USERNAME/it-support-github-portfolio.git
cd it-support-github-portfolio
```
