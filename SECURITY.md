# Security policy

This is a public lab portfolio. Use only personal systems or systems for which you have explicit authorization.

- Never commit credentials, secrets, API keys, tokens, SSH keys, or `.tfstate`.
- Never upload employer/client data, healthcare or patient information, internal network topology, proprietary tickets or screenshots.
- Replace identifiers in examples with fictional values.
- Inspect output files before sharing; even diagnostic logs may contain hostnames or usernames.
- Run scripts with least privilege and review commands before executing.
- AWS resources may cost money; run `terraform destroy` when finished.

For security concerns, open a GitHub security advisory rather than publishing a secret in an issue.
